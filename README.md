# 🏦 Loan Repayment Predictor

A full-stack machine learning system that predicts whether a loan applicant is likely to repay on time. Built with an ensemble ML model served via a FastAPI backend and a Streamlit frontend.

---

> ⚠️ The API is hosted on Render's free tier — first request may take ~30 seconds to wake up.

## 🧠 How It Works

A user enters applicant details (credit score, loan history, utilization, etc.) into the Streamlit UI. The frontend sends the data to the FastAPI backend, which runs it through a trained ML ensemble and returns a prediction with a confidence score.

```
User → Streamlit UI → FastAPI Backend → ML Ensemble Model → Prediction + Confidence Score
```

## 🤖 Model Architecture

The core is a **soft-voting ensemble** of four models trained on a SMOTE-balanced dataset:

| Model | Role | Weight |
|---|---|---|
| XGBoost | Captures non-linear patterns and feature interactions | 40% |
| Random Forest | Robust to outliers, handles high variance well | 40% |
| Logistic Regression (full features) | Linear baseline with scaled features | 10% |
| Logistic Regression (credit specialist) | Specialist model focused only on credit score and utilization | 10% |

### Feature Engineering

Beyond raw inputs, three engineered features are derived before prediction:

- **`distress_score`** — `credit_utilization × (late_payments + 1)` — amplifies risk when high utilization meets missed payments
- **`secured_loan_ratio`** — `secured / (secured + unsecured + 1)` — higher ratio signals more collateral-backed debt, lower risk
- **`debt_to_age_ratio`** — `unsecured_loans / (age + 1)` — flags younger applicants carrying heavy unsecured debt

### Rule-Based Override

Applicants with a credit score below **600** are immediately flagged as high risk without running through the ML model. This mirrors real-world credit policy hard cutoffs.

## 🛠️ Getting Started

### Prerequisites

- Python 3.9+
- pip

### 1. Clone the repository

```bash
git clone https://github.com/SannidhyaSinha1/Loan-Predictor-Model.git
cd Loan-Predictor-Model
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Set up environment variables

Create a `.env` file in the root directory:

```
API_KEY=your_secret_key_here
```

### 4. Train the model

```bash
python train_model.py
```

This generates `final_model.joblib` in the project root.

### 5. Start the API server

```bash
uvicorn api:app --reload
```

API will be running at `http://127.0.0.1:8000`. Visit `/docs` for the interactive Swagger UI.

### 6. Launch the Streamlit frontend

In a new terminal:

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## 🔌 API Reference

**Base URL:** `https://loan-predictor-api-9h1c.onrender.com`  
**Authentication:** Pass your API key in the request header as `X-API-Key`

### `POST /predict`

Predicts loan repayment likelihood for an applicant.

**Request Body:**

```json
{
  "credit_score": 720,
  "credit_utilization": 0.30,
  "late_payments": 0,
  "secured_loans": 1,
  "unsecured_loans": 2,
  "age": 35,
  "credit_card_loan_account": 2,
  "closed_account_count": 5
}
```

> Note: `credit_utilization` is a decimal — pass `0.30` for 30%.

**Response:**

```json
{
  "prediction_is_yes": true,
  "final_confidence_score": 0.8741,
  "analysis": "Prediction generated by an enhanced machine learning ensemble.",
  "input_features": { ... }
}
```

| Field | Description |
|---|---|
| `prediction_is_yes` | `true` = likely to repay on time, `false` = high risk |
| `final_confidence_score` | Probability of timely repayment (0.0 – 1.0) |

### `GET /`

Health check endpoint. Returns `{ "status": "ok" }`.
